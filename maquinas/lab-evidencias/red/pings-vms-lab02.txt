# Pings entre VMs — Lab 02, Sección 7 (evidencia)

> Fecha: 21/08/2026 — red de la casa (192.168.1.0/24, router 192.168.1.1)
> Las 3 VMs clonadas con bridge al Wi-Fi del host, DHCP del router de casa.

## Topología de red del momento

| VM | SO | IP (DHCP casa) | Rol |
|---|---|---|---|
| slackware-15.0 | Slackware 15.0 | `192.168.1.13` | VM 1 |
| solaris-11.4 | Oracle Solaris 11.4 | `192.168.1.11` | VM 2 |
| windows-server-gui | Windows Server 2025 GUI | `192.168.1.14` | VM 3 |

> Nota: en la universidad las VMs usan IPs estáticas 10.2.78.74/.75/.76 vía auto-detección al boot (script auto-red). En casa toman DHCP automáticamente.

## Matriz de resultados (21/08/2026, red de la casa)

| Origen → Destino | Resultado |
|---|---|
| Slackware (.13) → Solaris (.11) | ✅ 2/2, 0% loss (rtt ~1.6 ms) |
| Slackware (.13) → Windows (.14) | ✅ 2/2, 0% loss (rtt ~2.0 ms) |
| Slackware (.13) → Internet (8.8.8.8) | ✅ 2/2, 0% loss (rtt ~11.8 ms) |
| Solaris (.11) → Slackware (.13) | ✅ alive |
| Solaris (.11) → Windows (.14) | ✅ alive |
| Solaris (.11) → Internet (8.8.8.8) | ✅ alive |
| Windows (.14) → Slackware (.13) | ✅ 2/2, 0% loss (rtt ~1.5 ms) |
| Windows (.14) → Solaris (.11) | ✅ 2/2, 0% loss (rtt ~2.5 ms) |
| Windows (.14) → Internet (8.8.8.8) | ✅ 2/2, 0% loss (rtt ~9 ms) |
