## Servidor: Solaris 11.4 (10.2.78.75)

### Paquete (ya instalado)
pkg list samba
# service/network/samba 4.7.6-11.4.0.0.1.14.0

### Servidor SMB nativo de Solaris (SMF) - habilitado y escucha 445
svcadm enable svc:/network/smb/server
svcadm enable svc:/system/idmap          # dependencia requerida por smbd
netstat -an | grep .445                  # *.445 LISTEN

### Carpeta compartida y dataset ZFS
mkdir -p /export/compartido
groupadd shared
usermod -G shared claudia admin
chown -R claudia:shared /export/compartido
chmod 770 /export/compartido
zfs create -o mountpoint=/export/compartido rpool/export/compartido
zfs set sharesmb=on rpool/export/compartido

### NOTA IMPORTANTE: el servidor nativo (svc:/network/smb/server) tuvo
### problemas de sincronizacion de passwords SMB con usuarios locales
### (LOGON_FAILURE). Solucion final: usar Samba clasico del mismo paquete.

## Servidor Samba clasico (solucion que funciono)

### Configuracion /etc/samba/smb.conf
[global]
   workgroup = WORKGROUP
   server string = Servidor SAMBA Solaris (Lab 02)
   security = user
   passdb backend = tdbsam
   map to guest = Bad User
   server min protocol = SMB2
[compartido]
   path = /export/compartido
   writable = yes
   valid users = claudia admin
   create mask = 0660
   directory mask = 0770

### Usuarios SMB (backend tdbsam)
smbpasswd -a claudia    # Added user claudia
smbpasswd -a admin      # Added user admin
pdbedit -L              # claudia:100, admin:104

### Levantar Samba clasico
svcadm disable svc:/network/smb/server   # apagar nativo
/usr/sbin/smbd -D                        # Samba clasico, escucha 445
