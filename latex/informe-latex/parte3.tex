\section{VI --- conceptos clave}

VI tiene 3 modos: \textbf{Normal} (navegar, borrar, copiar --- es el inicial), \textbf{Inserción} (escribir; se entra con \texttt{i} o \texttt{a} y se sale con \texttt{Esc}) y \textbf{Comando} (guardar, salir, buscar, reemplazar; se entra con \texttt{:}). Las teclas significan \emph{verbos}, no letras que se escriben.

Desglose de los comandos más preguntados:
\begin{itemize}
  \item \texttt{:1,4s/a/-/g}: \texttt{1,4} = rango de líneas · \texttt{s} = substitute · \texttt{/a/} = patrón · \texttt{-} = reemplazo · \texttt{g} = global (todas las de cada línea).
  \item \texttt{:\%s/al/\#\#/g}: \texttt{\%} = todo el archivo (equivalente a \texttt{1,\$}); el resto igual.
  \item \texttt{dw}: \texttt{d} = delete (verbo) + \texttt{w} = word (objeto). VI combina verbos+objetos: \texttt{dd} borra línea, \texttt{5dd} borra 5 líneas.
  \item \texttt{u} / \texttt{Ctrl+r}: deshacer / rehacer (historial de cambios en memoria).
  \item \texttt{G} / \texttt{5G} / \texttt{7G}: ir a la última línea / línea 5 / línea 7.
  \item \texttt{gUU}: línea completa a mayúsculas (\texttt{guu} = minúsculas, \texttt{gUw} = palabra).
  \item \texttt{yy} + \texttt{p}: yank (copiar línea) + paste (pegar después; \texttt{P} pega antes).
  \item \texttt{/palabra}: buscar hacia adelante; \texttt{n} siguiente, \texttt{N} anterior.
  \item \texttt{:w} guardar sin salir · \texttt{:wq} guardar y salir · \texttt{:q!} salir descartando.
  \item \texttt{:set number}: mostrar números de línea.
\end{itemize}

Preguntas típicas de sustentación (VI):
\begin{enumerate}
  \item \textbf{¿Por qué no puedo escribir al abrir VI?} Porque se está en modo Normal; hay que pulsar \texttt{i} para entrar a modo Inserción.
  \item \textbf{¿Diferencia entre \texttt{i} y \texttt{a}?} \texttt{i} inserta antes del cursor, \texttt{a} después (append).
  \item \textbf{¿Qué significa la \texttt{g} en \texttt{:1,4s/a/-/g}?} Global: reemplaza todas las coincidencias de cada línea; sin \texttt{g} solo la primera.
  \item \textbf{¿Qué es \texttt{\%} en \texttt{:\%s/al/\#\#/g}?} Todo el archivo.
  \item \textbf{¿Cómo deshacer?} \texttt{u} en modo normal.
  \item \textbf{¿Cómo guardar sin salir / guardar y salir?} \texttt{:w} y \texttt{:wq}.
  \item \textbf{¿Cómo salir sin guardar?} \texttt{:q!} (el \texttt{!} fuerza y descarta).
  \item \textbf{¿Qué hace \texttt{5G}?} Ir a la línea 5.
  \item \textbf{¿Cómo copiar y pegar una línea?} \texttt{yy} copia, \texttt{p} pega.
  \item \textbf{¿Cómo buscar una palabra?} \texttt{/palabra}, \texttt{n} para la siguiente.
\end{enumerate}

\section{SAMBA / SMB --- conceptos clave}

\begin{itemize}
  \item \textbf{SMB}: protocolo de Windows para compartir archivos en red (Server Message Block).
  \item \textbf{SAMBA}: implementación libre de SMB para Unix/Linux/Solaris: hace que un sistema Unix ``hable Windows''.
  \item \textbf{Share}: recurso compartido: la carpeta publicada para la red.
  \item \textbf{Puerto 445/TCP}: donde escucha SMB.
  \item \textbf{smbpasswd / tdbsam}: base de usuarios SMB, separada de los usuarios del sistema.
  \item \textbf{security = user}: cada acceso exige usuario+contraseña.
\end{itemize}

Desglose de comandos clave (servidor):
\begin{itemize}
  \item \texttt{ps -ef | grep smbd}: \texttt{ps} = process status · \texttt{-e} = todos los procesos · \texttt{-f} = formato completo · \texttt{grep smbd} = filtra el daemon de Samba.
  \item \texttt{netstat -an | grep .445}: \texttt{-a} todas las conexiones · \texttt{-n} numérico · puerto 445 = SMB; \texttt{LISTEN} = esperando clientes.
  \item \texttt{testparm}: valida la sintaxis de \texttt{/etc/samba/smb.conf} y muestra la configuración efectiva.
  \item \texttt{smbpasswd -a claudia}: agrega el usuario a la base SMB; la contraseña SMB es INDEPENDIENTE de la del sistema (\texttt{-x} elimina, sin opción cambia la contraseña).
  \item \texttt{pdbedit -L}: lista los usuarios SMB con su uid Unix.
  \item \texttt{/usr/sbin/smbd -D}: el daemon de Samba corriendo en segundo plano (\texttt{-D} = daemon).
\end{itemize}

Desglose de comandos clave (cliente):
\begin{itemize}
  \item \texttt{smbclient -L //IP -U usuario}: \texttt{-L} enumera los shares del servidor.
  \item \texttt{smbclient //IP/compartido -U usuario -c 'put x; get y'}: \texttt{-c} ejecuta comandos sin entrar a la sesión interactiva (\texttt{put} sube, \texttt{get} baja).
  \item \texttt{net use \\\\IP\textbackslash compartido /user:usuario contraseña}: mapeo de unidad de red en Windows (ruta UNC).
  \item \texttt{smbstatus}: muestra las sesiones activas (quién está conectado, desde qué IP, con qué versión de SMB).
\end{itemize}

Parámetros de \texttt{smb.conf}:
\begin{itemize}
  \item \texttt{workgroup = WORKGROUP}: grupo de trabajo estilo Windows al que se anuncia el servidor.
  \item \texttt{server string}: descripción que ven los clientes al enumerar.
  \item \texttt{passdb backend = tdbsam}: dónde se guardan las contraseñas SMB (base de datos local).
  \item \texttt{map to guest = Bad User}: un usuario inexistente NO se convierte en invitado (más seguro).
  \item \texttt{path = /export/compartido}: la carpeta REAL del disco que se comparte.
  \item \texttt{writable = yes}: se puede escribir (si \texttt{no} = solo lectura).
  \item \texttt{valid users = claudia admin}: lista blanca: SOLO estos usuarios pueden entrar.
  \item \texttt{create mask = 0660} / \texttt{directory mask = 0770}: permisos de archivos/carpetas nuevas (octal: dueño, grupo, otros).
\end{itemize}

Preguntas típicas de sustentación (SAMBA):
\begin{enumerate}
  \item \textbf{¿Qué es Samba?} Implementación libre del protocolo SMB para que sistemas Unix compartan archivos con Windows.
  \item \textbf{¿Qué es un share?} Una carpeta publicada en la red (path + permisos + usuarios).
  \item \textbf{¿En qué puerto escucha SMB?} 445/TCP.
  \item \textbf{¿Por qué \texttt{smbpasswd -a}?} Porque los usuarios SMB tienen su propia contraseña, separada de la del sistema.
  \item \textbf{¿Qué significa \texttt{security = user}?} Autenticación obligatoria por usuario; sin credenciales no se accede.
  \item \textbf{¿Qué hace \texttt{valid users}?} Restringe el share solo a esos usuarios.
  \item \textbf{¿Para qué sirve \texttt{testparm}?} Validar la configuración antes de reiniciar el servicio.
  \item \textbf{¿Cómo verifico quién está conectado?} \texttt{smbstatus}.
  \item \textbf{¿Cómo conecto desde Windows?} \texttt{net use \\\\IP\textbackslash share /user:usuario contraseña}.
  \item \textbf{¿Qué es un mask 0770?} El dueño y el grupo tienen permisos completos; los demás, ninguno.
\end{enumerate}
